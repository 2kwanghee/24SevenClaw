Ralph 파이프라인 정제 요청이군요. 위 metaprompt 지침에 따라 구현 스펙만 출력하겠습니다.

## 목표
대시보드 프로젝트 상태/인테이크 위젯을 recharts 기반으로 전환하고 상태 라벨 전수 한글화 + hover 시 프로젝트 상세(토큰/기간/계정) 표시를 구현한다.

## 가정 (Assumptions)
- `GET /observability/projects/{id}/summary`(CE-402)는 이미 구현 완료 상태라고 가정한다 — 미완료 시 hover 상세는 fetch 실패 처리(로딩/에러 상태로 폴백)하고, 이 부분은 CE-402 완료 후 통합 테스트 필요 (금지범위: 백엔드는 CE-402 소관이므로 API 자체는 건드리지 않음).
- 상태값 전수 목록은 실제 스키마(`clickeye-contracts` 또는 API 응답)에서 확인 후 채운다. 추측으로 상태 키를 나열하지 않는다 — 구현 단계에서 실제 enum을 조회해 결정.
- recharts는 React 19 / Tailwind v4와 호환성 이슈가 보고된 바 있어(공식 지원은 되지만 일부 버전 조합에서 타입 경고 발생 가능), 설치 직후 `pnpm build`로 우선 검증한다. 문제 발생 시 최신 recharts(v2.15+) 버전 고정.
- 계정 목록이 CE-400 동기화 전이라 비어있는 경우, "계정 동기화 대기"는 정적 문자열로 처리(별도 API 폴링 없음) — 보수적 선택.
- 프로젝트 목록 팝오버 상세 hover는 recharts `Tooltip`의 `content` prop에 커스텀 컴포넌트를 꽂는 방식으로, 별도 팝오버 라이브러리(shadcn popover 등) 신규 도입 없이 구현한다 (금지범위: shadcn 대량 도입 금지).

## 대상 파일
- `clickeye-web/package.json` — recharts 의존성 추가
- `clickeye-web/app/dashboard/page.tsx` — 상태 위젯(도넛/바)·인테이크 위젯을 recharts 컴포넌트로 교체, hover 상세용 상태 관리(선택된 세그먼트/항목) 추가. 현재 raw `{key}` 렌더링 부분(49번 줄 부근) 교체 대상.
- `clickeye-web/lib/i18n/` (또는 기존 i18n 딕셔너리 위치 — 실제 경로는 레포 탐색 후 확정) — `observability.dashboard.status.*` (ko/en) 키 추가, `intakeFunnel` 값 변경, 인테이크 내부 상태(pending_review 등) 한글화 키 추가
- `clickeye-web/lib/api/observability.ts` (또는 기존 observability API 클라이언트 파일 — 실제 경로 확인 필요) — `GET /observability/projects/{id}/summary` 호출 함수 추가 (CE-402 계약 스키마 참조, `clickeye-contracts` 타입 사용)
- 신규: `clickeye-web/components/dashboard/status-tooltip.tsx` (또는 기존 대시보드 위젯 컴포넌트 디렉토리 내) — recharts 커스텀 Tooltip 카드 컴포넌트 (토큰/기간/계정 렌더)

## 구현 단계
1. `clickeye-contracts`에서 CE-402 summary 응답 스키마와 프로젝트 상태 enum을 확인한다 (금지범위 준수: 스키마 자체는 수정하지 않고 참조만).
2. recharts 설치 후 `pnpm build`로 React19/Tailwind v4 호환성 즉시 검증.
3. i18n 딕셔너리에 `observability.dashboard.status.*` (상태 enum 전수, ko/en) 추가, `intakeFunnel` 값을 "인테이크"로 변경, 인테이크 내부 상태 키 추가.
4. `dashboard/page.tsx`의 conic-gradient 도넛 → recharts `PieChart`로, div-width 막대 → recharts `BarChart`로 교체. 기존 CSS 변수(`--text-*`) 값을 recharts `fill`/`stroke`에 매핑, `dark:` 클래스 대응 위해 컨테이너 레벨에서 색상 분기.
5. 라벨 `text-xs`→`text-sm`, 수치 강조 폰트 스케일 업 (기존 Tailwind 클래스 조정만, 신규 스타일 시스템 도입 없음).
6. 상태 세그먼트 hover 시 summary API를 호출해 커스텀 Tooltip 카드 렌더 (토큰 사용량, first~last activity 기간, 계정 목록). 계정 빈 배열이면 "계정 동기화 대기" 표시.
7. 상태별 다건일 경우 프로젝트 목록을 우선 팝오버(리스트)로 보여주고, 리스트 항목 hover 시 위 상세 Tooltip 재사용.
8. 인테이크 위젯도 동일 패턴(recharts 전환 + 한글화)으로 교체. hover 상세는 인테이크에 요구되지 않았으므로 추가하지 않는다 (범위 외 확장 금지).
9. 로딩/빈 상태/에러 상태 기존 분기 로직 유지한 채 recharts 컴포넌트로 감싼다.
10. `pnpm lint`, `pnpm typecheck`, `pnpm build` 통과 확인.

## 테스트
- 컴포넌트 테스트(기존 테스트 프레임워크 — Vitest/Jest 확인 후 동일 방식): 상태 라벨이 한글로 렌더되는지, `intakeFunnel` 라벨 변경 확인, summary API 실패 시 폴백 렌더 확인, 계정 빈 배열 시 "계정 동기화 대기" 렌더 확인.
- 수동 검증: SIP-4 프로젝트 데이터로 hover 시 토큰/기간/계정 실데이터 렌더 확인 (수용 기준 명시).
- 다크모드 토글 + 반응형 뷰포트(모바일/데스크톱) 수동 확인.
- 커버리지 ≥70% 유지.
