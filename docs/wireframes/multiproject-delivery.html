I-14 · 이 화면이 대체하는 것

기존 /delivery는 벤토 카드 그리드였고 카드를 누르면 곧바로 콘솔로 진입했습니다. 리스트 + 슬라이드 요약으로 바꿔 "무엇을 열지" 판단을 먼저 하게 합니다. 같은 목록을 중복 노출하던 1뎁스 프로젝트 메뉴는 제거했습니다.

이 화면은 목표 상태다 — 2026-07-29 실제 구현과 다른 부분

구현됨: 사이드바 정리 · 리스트 + 슬라이드 패널 · 행 선택≠진입 · 현재 단계(session.phase) · 서브태스크 집계 · 마지막 갱신. 선택된 1건만 지연 조회한다.

미구현: 위 표의 진행률 %는 전용 필드가 없어 서브태스크 완료 비율로 파생한다. 티켓 완주·검증은 티켓이 아니라 서브태스크 기준이다. 막힌 것은 HumanIntegrationGate가 미구현(Stage 1), 구독 시트는 웹 api-client.ts에 seat 호출이 없어 둘 다 "도입 후 제공" 자리표시로만 노출한다 — 값을 추정하지 않는다.

타임스탬프는 상대 시각이 아니라 결정적 UTC 절대 시각이다. 상대 시각은 SSR·클라이언트 값이 달라 하이드레이션 불일치를 만들고, 우회용 mounted 게이트는 이 프로젝트 lint 규칙(효과 내 동기 setState)에서 error다.

이 와이어프레임이 지킨 제약

  • 정확한 잔여 토큰 숫자를 표시하는 요소가 없습니다 — 파생 상태 + 추정 여유도 + 근거만.
  • 비밀값을 보여주는 요소가 없습니다 — secret_ref 와 fingerprint 만.
  • FAILED는 완료·성공 집계와 분리했습니다.
  • Feature Flag off 상태 화면을 포함합니다.
  • 기존 사이드바 최상위 메뉴와 프로젝트 탭을 교체하지 않고 가산만 했습니다.
  • 계약·견적·인사·CRM 요소를 넣지 않았습니다.
